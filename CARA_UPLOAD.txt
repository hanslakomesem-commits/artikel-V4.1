CARA UPLOAD KE GITHUB PAGES (cara upload langsung):
1. Extract ZIP ini.
2. Upload SEMUA file di dalam folder langsung ke ROOT repository GitHub.
3. Commit changes.
4. Settings > Pages > Deploy from a branch.
5. Branch: main, folder: /(root), lalu Save.
6. Tunggu deploy selesai dan buka link GitHub Pages.
7. Jika masih versi lama, tekan Ctrl+F5.
